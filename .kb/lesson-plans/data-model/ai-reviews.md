# Schema

| Column | Type | Description |
|--------|------|-------------|
| `id` | TEXT PK | UUID-style primary key. |
| `plan_id` | TEXT FK→lesson_plans | Unique — one review per plan (CASCADE delete). |
| `scores` | JSONB | Per-dimension rubric scores from AI. |
| `executive_summary` | TEXT | Natural language summary of the review. |
| `total_score` | INTEGER | Sum of all dimension scores. |
| `percentage` | INTEGER | Normalized percentage (0-100). |
| `performance_level` | TEXT | Label like "Excellent", "Good", "Needs Improvement". |
| `strengths` | JSONB | Array of strength descriptions. |
| `improvements` | JSONB | Array of suggested improvement areas. |
| `ai_summary_notes` | JSONB | Structured notes from AI analysis. |
| `additional_data` | JSONB | Extensible metadata from the review. |
| `status` | TEXT | `pending` or `reviewed` — supervisor review status. |
| `supervisor_comment` | TEXT | Optional human comment from supervisor. |
| `created_at` | TIMESTAMPTZ | Row creation timestamp. |
| `updated_at` | TIMESTAMPTZ | Auto-updated via trigger. |

## Indexes

- `idx_ai_reviews_status` on (`status`) — supervisor dashboard filtering.

## Key relationships

- 1:1 with `lesson_plans` via `plan_id` (UNIQUE constraint ensures one review per plan).

Reviews are linked 1:1 to [lesson_plans](lesson-plans.md). Generated by the [generate-lesson-review](../api/edge-functions.md) edge function. Reviewed by supervisors via [LessonPlanReview](../ui/lesson-plan-review.md). Teachers view results in [LessonPlanner](../ui/lesson-planner.md). RLS enforced via [policies](../security/rls-policies.md).
