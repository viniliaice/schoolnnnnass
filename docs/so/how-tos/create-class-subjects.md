# Sida loo Sameeyo Qoondaynta Fasalka-Maadada

U qoondee macallimiinta fasallo iyo maadooyin gaar ah si ay u gelin karaan natiijooyinka imtixaanka.

## Waxyaabaha loo baahan yahay

- Door admin ah
- Macallimiin diiwaangashan
- Fasallo iyo maadooyin diiwaangashan

## Tallaabooyinka

1. Guji **Class Subjects** bar-ka bidix.
2. Waxaad arki doontaa jaantus qoondaynta.
3. Guji **Add Assignment**.
4. Xulo:
   - **Class:** tusaale "Grade 5-A"
   - **Subject:** tusaale "Mathematics"
   - **Teacher:** ka xulo liiska macallimiinta
5. Guji **Save**.

### Qoondayn badan (bulk)

Macallin mid ku qoondee fasallo badan:

1. Tag **Users** bar-ka bidix.
2. Raadso macallinka oo guji **Edit**.
3. Hoos **Assigned Classes**, hubi dhamaan fasallada uu bariyo.
4. Hoos **Assigned Subjects**, hubi dhamaan maadooyinka uu bariyo.
5. Guji **Save**.

### Ka saar qoondayn

1. **Class Subjects**, raadso qoondaynta.
2. Guji summada tirtirka.
3. Xaqiiji ka saarista.

Tani ma tirtiraysid macallinka ama fasalka — waxay kaa saaraysaa qoondaynta oo keliya.

## Xaqiijin

- Dashboard-ka macallinku wuxuu tusayaa fasallada loo qoondeeyay oo keliya.
- Macallimiintu waxay gelin karaan natiijooyinka qoondayntooda oo keliya.
- Kormeerayaashu waxay arkaan qoondaynta mogofka kormeerka.

## Cillad saarista

**Dhibaato:** Macallinku kuma soo bixin liiska.
**Xal:** Hubi in `assignedClasses` iyo `assignedSubjects` macallinka ay ku jiraan fasalka iyo maadada.

**Dhibaato:** Macallinku ma arki karo fasalka dashboard-kiisa.
**Xal:** Abuur qoondayn fasalka-macallinka ah.
