# Sida loo Galiyo oo loo Xaqiijiyo Natiijooyinka Imtixaanka

Hawsha imtixaanku waxay leedahay laba heer: macallimiintu way galiyaan, kormeerayaashuna way xaqiijiyaan.

## Waxyaabaha loo baahan yahay

- Door macallin ama admin (gelinta)
- Door kormeere (xaqiijinta)
- Sannad dugsiyeed iyo xilli firfircoon
- Qoondayn fasalka-maadada

## Gelinta natiijooyinka imtixaanka (macallin)

1. Guji **Results** bar-ka bidix.
2. Xulo:
   - **Class:** fasalkaaga
   - **Subject:** maadadaada
   - **Month:** bil xilliga ku jirta
   - **Exam Type:** CA, Homework, Classwork, Quiz, ama Attendance
3. Liiska ardayda ayaa soo baxaya.
4. Arday kasta:
   - Geli **Score** (tusaale 85)
   - Geli **Total** (tusaale 100)
   - Ikhtiyaar ahaan ku dar **Comment**
5. Guji **Save All**.

Natiijooyinku waxay ku kaydmaan xaalad `pending`.

### Noocyada imtixaanka

| Nooc | Ujeeddo | Lagama maarmaan? |
|------|---------|------------------|
| CA | Qiimaynta Joogtada ah | Haa (mid CA ama Homework+Classwork) |
| Homework | Shaqada Guriga | Haa (Classwork la jirto) |
| Classwork | Shaqada Fasalka | Haa (Homework la jirto) |
| Quiz | Tijaabo degdeg ah | Haa |
| Attendance | Xaadirinta | Loo baahan ma aha |
| Midterm | Imtixaanka xilliyeed | Ikhtiyaar |
| Final | Imtixaanka dhamaadka | Ikhtiyaar |

### Shuruudaha gelinta bishii

- **Quiz** waa lagama maarmaan arday kasta
- **Coursework** waa lagama maarmaan — waxaa buuxin kara:
  - CA arday kasta, AMA
  - Homework iyo Classwork labaduba arday kasta
- **Attendance** waa la arki karaa laakiin looma baahna

## Xaqiijinta natiijooyinka imtixaanka (kormeere)

1. Guji **Verifications** bar-ka bidix.
2. Dib u eeg gelitaanka sugaya — oo loo kala saaray macallin, fasalka, maadada, bisha.
3. Gelitaan kasta:
   - Hubi tirada ardayda la galay iyo tirada diiwaangashan
   - Dib u eeg buundooyinka
   - Xaqiiji nooca imtixaanka iyo bisha
4. Guji **Approve** si aad u daabacdo warbixinnada waalidka.
5. Guji **Reject** oo sabab la socoto haddii khalad jiro.

## Xaqiijin

- Macallimiintu waxay arkaan "pending" ilaa la xaqiijiyo.
- Kormeerayaashu waxay arkaan boqolleyda dhammaystirka.
- Waalidku waxay arkaan natiijooyinka xaqiijinta ka dib oo keliya.

## Cillad saarista

**Dhibaato:** Macallinku ma gelin karo bisha.
**Xal:** Hubi in bisha ku jirto xilliga hadda.

**Dhibaato:** Natiijooyinku kuma soo baxaan warbixinnada waalidka.
**Xal:** Kormeeruhu waa inuu xaqiijin marka hore. Hubi safka xaqiijinta.

**Dhibaato:** Tirada ardayda khaldan.
**Xal:** Hubi qoondaynta fasalka-maadada iyo diiwaangelinta ardayda.
