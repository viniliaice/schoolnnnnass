# Tababarka: Waalid Bilow

Tababarkani wuxuu ku barayaa sida loo isticmaalo nidaamka waalidka — laga bilaabo galitaanka ilaa daawashada warbixinta imtixaanka ilmahaaga.

## Waxaad u baahan tahay

- Email-ka iyo password-ka waalidka
- Ugu yaraan hal ilmo oo dugsi ka diiwaangashan
- Browser

## Tallaabada 1: Soo gal

1. Fur URL-ka barnaamijka.
2. Geli email-kaaga waalid iyo password-ka.
3. Guji **Sign In**.

Waxaad ku soo dagi doontaa **Dashboard-ka Waalid** oo tusaya carruurtaada, fasalladooda, iyo hawlgalkii ugu dambeeyay.

## Tallaabada 2: Daawado carruurtaada

1. Guji **Children** bar-ka bidix.
2. Waxaad arki doontaa liiska carruurtaada oo leh:
   - Magaca iyo fasalka
   - Buundooyinka imtixaanka ee dhawaa
   - Soo koobida xaadirinta

Guji ilmaha si aad u aragto xogtooda oo dhan.

## Tallaabada 3: Hubi natiijooyinka imtixaanka

1. Guji **Exam Results** bar-ka bidix.
2. Xulo ilmaha liiska.
3. Xulo bisha iyo xilliga.
4. Waxaad arki doontaa maado walba oo leh buundooyin:

| Nooca | Sharaxaad |
|-------|-----------|
| CA | Qiimaynta Joogtada ah |
| Homework | Shaqada Guriga |
| Classwork | Shaqada Fasalka |
| Quiz | Su'aalaha |
| Attendance | Xaadirinta |

## Tallaabada 4: Daawado warbixinta bishii

1. Guji **Monthly Report** bar-ka bidix.
2. Xulo ilmaha iyo bisha.
3. Warbixintu waxay tusaysaa:
   - Maado kasta oo la kala saaray
   - Celcelis buundo maaddiiba
   - Darajada fasalka
   - Faallooyinka macallinka

## Tallaabada 5: Daawado warbixinta xilliyeed

1. Guji **Midterm Report** bar-ka bidix.
2. Xulo ilmaha iyo xilliga.
3. Warbixintu waxay tusaysaa:
   - Buundooyinka isugeynta ah xilliga oo dhan
   - Darajooyinka maadada
   - Isbarbardhigga celceliska fasalka

## Tallaabada 6: Qaado su'aalo (haddii la qoondeeyay)

Macallinku wuxuu qoondeyn karaa su'aalo. Waad tijaabin kartaa:

1. Guji **Quizzes** bar-ka bidix.
2. Arag su'aalaha diyaarka u ah carruurtaada.
3. Guji su'aasha si aad u aragto su'aalaha iyo jawaabaha.

## Tallaabada 7: Hubi xaadirinta

Qaybta xaadirinta waxay tusaysaa diiwaanka maalinlaha ah:

- Cagaar = joogay
- Guduud = ma joogin
- Jaalle = daahay

Waxaad shaandheyn kartaa taariikhda iyo ilmaha.

## Waxaad dhammaysay

Waxaad baratay sida loo isticmaalo nidaamka waalidka oo dhan: daawado carruurta → hubi natiijooyinka → akhri warbixinnada → la soco xaadirinta. Hadda waxaad la socon kartaa horumarka ilmahaaga maado walba iyo xilli walba.
