# Tababarka: Macallin Bilow

Tababarkani wuxuu ku barayaa sida loo isticmaalo nidaamka macallinka — laga bilaabo galitaanka ilaa soo gelinta imtixaannada koowaad.

## Waxaad u baahan tahay

- Email-ka iyo password-ka macallinka
- Fasallo iyo maadooyin kuu qoondeysan (oo uu sameeyay admin)
- Browser

## Tallaabada 1: Soo gal

1. Fur URL-ka barnaamijka.
2. Geli email-kaaga macallin iyo password-ka.
3. Guji **Sign In**.

Waxaad ku soo dagi doontaa **Dashboard-ka Macallin** oo tusaya fasalladaada, maadooyinkaaga, iyo hawlgalkii ugu dambeeyay.

## Tallaabada 2: Daawado fasalladaada

Dashboard-kaagu wuxuu tusayaa:

- **Fasallada laguu qoondeeyay** — fasallada aad bariso
- **Maadooyinka laguu qoondeeyay** — maadooyinka aad mas'uul ka tahay
- **Ardayda** — tirada ardayda fasalkiiba

Guji **Students** bar-ka bidix si aad u aragto liiska ardayda.

## Tallaabada 3: Soo geli natiijooyinka imtixaanka

Kani waa shaqadaada maalinlaha ah.

1. Guji **Results** bar-ka bidix.
2. Xulo fasalka (tusaale "Grade 5-A").
3. Xulo maadada (tusaale "Mathematics").
4. Xulo bisha (tusaale "January").
5. Xulo nooca imtixaanka (tusaale "CA").
6. Arday kasta, geli:
   - **Score** — buundada ardayga (tusaale 85)
   - **Total** — buundada ugu badnaan (tusaale 100)
7. Guji **Save**.

Natiijooyinku waxay ku kaydmaan xaalad "pending" — kormeeruhu waa inuu xaqiijin ka hor warbixinnada waalidka.

## Tallaabada 4: Qor xaadirinta

1. Guji **Attendance** bar-ka bidix.
2. Xulo fasalka iyo taariikhda.
3. Arday kasta, calaamadee:
   - **Present** (cagaar) — ardaygu wuu joogay
   - **Absent** (guduud) — ardaygu ma joogin
   - **Late** (jaalle) — ardaygu wuu daahay
4. Geli faallo haddii loo baahdo.
5. Guji **Save**.

## Tallaabada 5: Qoondee shaqo guri

1. Guji **Homework** bar-ka bidix.
2. Xulo fasalka iyo maadada.
3. Geli cinwaan (tusaale "Cutubka 3 Mashaakilka").
4. Geli sharaxaad (ikhtiyaar).
5. Deji taariikhda dhamaynta.
6. Guji **Assign**.

## Tallaabada 6: Abuur su'aalo (quiz)

1. Guji **Quizzes** bar-ka bidix.
2. Guji **Create Quiz**.
3. Xulo fasalka, maadada, oo geli cinwaan.
4. Deji taariikhda furitaanka, dhamaynta, iyo wakhtiga (ikhtiyaar).
5. Ku dar su'aalaha — dooro:
   - **Multiple choice** — ikhtiyaarro, calaamadee midda saxda ah
   - **Direct answer** — ardaygu wuxuu galiyaa jawaabtiisa
6. Guji **Publish**.

## Tallaabada 7: Isticmaal qorsheeye casharrada AI

1. Guji **Lesson Plans** bar-ka bidix.
2. Guji **Create Plan**.
3. Xulo usbuuca, maadada, iyo fasalka.
4. Xilli kasta, buuxi:
   - **Topic** — waxaad baraysid
   - **Objective** — ujeeddada barashada
   - **Activities** — waxa ardaydu qaban doonaan
5. Guji **Submit for Review**.

AI-ga wuxuu dib u eegi doonaa qorshahaaga oo wuxuu ku siin doonaa buundo 10 qaybood.

## Waxaad dhammaysay

Waxaad dhammaysay hawsha macallinka oo dhan: daawado fasallada → geli buundooyinka → qor xaadirinta → qoondee shaqo guri → samee su'aalo → qorshee casharro.
